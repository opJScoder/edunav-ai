# 🎓 EduNav AI

> ### **Your Career. Your Roadmap. Your Next Move.**
>
> An AI-powered personalized career and learning assistant that helps students discover career paths, identify skill gaps, build learning roadmaps, choose meaningful projects, and track their growth throughout college.

---

## 🚀 The Problem

Students are surrounded by endless courses, technologies, career options, and advice.

But most students still struggle with:

* **What should I learn next?**
* **Which career is right for me?**
* **What skills am I missing?**
* **Which projects are actually worth building?**
* **How do I prepare for internships and placements?**
* **Am I making meaningful progress?**

Generic roadmaps don't account for a student's **branch, semester, existing skills, interests, goals, or available time**.

### 💡 EduNav AI changes that.

---

## 🧭 What is EduNav AI?

**EduNav AI is a personalized career navigation system for students.**

It understands where a student is today, where they want to go, and creates a practical path between the two.

```text
Student Profile
      ↓
Skills + Interests + Goals
      ↓
Skill-Gap Analysis
      ↓
Personalized Roadmap
      ↓
Projects + Weekly Goals
      ↓
Progress Tracking
      ↓
Career Readiness
```

# ✨ Key Features

### 👤 Personalized Student Profile

Capture:

* Degree & branch
* Current semester
* Skills & interests
* Career goals
* Completed courses
* Projects
* Available study time

### 🧠 AI Career Assistant

A context-aware AI assistant that understands the student's profile and can answer questions about:

* Career choices
* Learning priorities
* Technologies
* Projects
* Internships
* Resume improvement

### 🎯 Skill-Gap Analysis

Compare:

**What you know → What your target career requires**

Identify:

* Strong skills
* Skills needing improvement
* Missing skills
* Prerequisites

### 🗺️ Personalized Learning Roadmap

Generate a dynamic roadmap based on:

* Career goal
* Current knowledge
* Semester
* Skill gaps
* Available time

### 💡 Smart Project Recommendations

Recommend projects that are actually useful for the student's growth.

Every recommendation explains:

> **Why this project? → What will you learn? → Which skill gap does it solve?**

### 📅 Weekly Learning Planner

Turn a long-term roadmap into realistic weekly tasks based on available study hours.

### 📈 Progress Dashboard

Track:

* Skill progress
* Roadmap completion
* Courses
* Projects
* Weekly goals
* Career readiness

### 📄 AI Resume Analysis

Upload a resume and receive:

* Resume insights
* Skill extraction
* Career alignment
* Missing skills
* Improvement suggestions

### 🔀 Multiple Career Paths

Explore and compare different careers based on the student's current profile.

### 🔄 Adaptive Roadmap

The roadmap evolves when students:

* Learn new skills
* Complete projects
* Upload a new resume
* Change career goals
* Change available study time

# 🧠 Intelligent Recommendation Engine

EduNav AI does not simply ask an LLM:

> *"Give this student a roadmap."*

Instead, it combines **structured recommendation logic + AI reasoning**.

```text
Student Data
     │
     ↓
Career Requirements
     │
     ↓
Skill Dependency Graph
     │
     ↓
Skill-Gap Analysis
     │
     ↓
Recommendation Engine
     │
     ↓
AI Personalization
     │
     ↓
Actionable Roadmap
```

Recommendations consider:

* Career relevance
* Current skill level
* Skill gaps
* Prerequisites
* Interests
* Semester
* Available time
* Existing projects

This makes recommendations **personalized, explainable, and actionable**.
